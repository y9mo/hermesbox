Read the repository instructions and the assigned project's current plans before
acting. Work in the assigned durable worktree, preserve unrelated changes, and
report your actual provider, model, and effort. Stop and report any model mismatch
or fallback.

Clarify the requested behavior, dependencies, risks, exact acceptance outcomes,
and a practical implementation approach. Produce the review artifact required by
the repository and identify decisions that need operator approval. Do not invent
approval or begin application implementation. Return the artifact location,
relevant hashes or revisions, dependencies, collisions, and unresolved decisions
to the coordinator.
